# ✈️ Boeing 737NG/MAX 标准力矩查询系统 (AMM 20-50-11 & BAC5009)

> **⚠️ 仅供参考，具体以当前手册为准！**  
> 本项目是基于波音 **737NG/MAX AMM 20-50-11 (Standard Torque Values)**、**BAC5009 (Bolt and Nut Installation)** 以及 **PSDS / Boeing Shop (BPS-F-69 / BPS-N-70)** 规范构建的纯前端渐进式 Web 应用 (PWA)，可直接托管至 **GitHub Pages**，支持桌面端与手机端一键切换及离线查询。

---

## ✨ 最新版本核心特性 (v4.0)

### 1. 五大核心功能模块（严格按机务工作流排序）
顶部导航栏按以下顺序组织五大模块：
1. **🔧 标准力矩查询**：采用清晰的四步递进式布局：
   - **模块 1 · 件号检索**：支持完整件号（如 `BACB30NN3K7`、`BACN10YN3CD`）或前 8 位基础件号模糊搜索，选中紧固件卡片后具有醒目的蓝色高亮边框与勾选徽章。
   - **模块 2 · 紧固件信息展示（整合去重小卡片模式）**：将紧固件基础属性与 Boeing Shop / PSDS 详细工程规范去重整合为 **12 宫格精简小卡片 (Small Card Grid)**，涵盖标称直径、标称螺纹尺寸、强度等级、头部型式与驱动、螺纹制式与旋向、材料与合金标准、采购与施工规范、表面镀层与润滑、夹持长度与总长、孔配合与扳拧工具、自锁/脱扣力矩限值 (Table 227) 以及垫圈与伸出量规范 (BAC5009)，并随当前选中的螺纹尺寸实时联动。
   - **模块 3 · 施工条件**：支持一键切换安装部件材料（金属结构 vs 复合材料结构 Table 215/216）、标称螺纹尺寸、干/湿润滑状态（Dry vs Lubricated/A-Finish）及拧紧方式（拧螺帽无密封胶 vs 拧螺杆头/有贴合面密封胶）。
   - **模块 4 · 查询结果**：自动生成**标准力矩查询路径推导面包屑**、当前工况英制/公制/英尺磅核心力矩大屏、全工况对比矩阵及同表全尺寸速查表。
2. **📘 基本定义**：系统梳理航空标准紧固件核心工程概念与物理定义，包含：
   - **件号命名规则图解**：以 `BACB30NN3K7M`（螺栓）与 `BACN10YN3CD`（自锁螺帽）为例逐段拆解；
   - **8 大几何与材料概念卡片**：标称直径 (Nominal Diameter)、标称螺纹尺寸 (Thread Size)、强度等级 (Fastener Class, KSI)、头部型式与驱动 (Head Style)、螺纹制式与旋向 (UNJF-3A/3B Right Hand)、材料与采购规范 (Material & Spec)、夹持长度 (Grip Size)、螺纹伸出量与垫圈规范；
   - **4 大力矩核心物理定义 + Table 227 速查表**：详解 **Running Torque (跑合力矩/自锁摩擦力矩)**、**RUN ON TORQUE (最大旋入力矩)**、**最大自锁力矩 (Max Locking Torque)** 与 **最小脱扣力矩 (Min Breakaway Torque - 螺帽复用标准)**。
3. **📐 施工规范**：完整收录 **AMM 20-50-11 2.C.(1)–(12)** 全部 12 条通用施工铁律、**BAC5009** 螺杆螺帽安装规范，并内置**扭力扳手加长接杆读数换算器**（`M = T × L / (L + E)`）。
4. **🗂️ BAC标准件字典**：内置 AMM 20-50-11 涉及的全部 **136 项波音 BAC 基础件号**（107 项 `BACB` 螺杆 + 29 项 `BACN` 螺帽）完整技术参数字典，支持按材料、头型、件号实时过滤并一键载入查询。
5. **📊 手册全表预览**：完整收录 **Table 201 至 Table 227 共 27 张原始手册力矩表**（包括已补齐的 Table 205、207、208、211、220），零空表遗漏。

### 2. 桌面端 / 手机端一键切换 (`🖥️ 桌面端` / `📱 手机端`)
- 顶栏右侧提供 **`🖥️ 桌面端` / `📱 手机端`** 切换按钮，并可根据屏幕宽度自动适配或手动强制切换。
- 在 **手机端模式 (`📱 手机端`)** 下，页面自动切换为单列紧凑视口，紧固件小卡片重构为高可读性的双列紧凑网格，方便机务人员在机坪或客舱现场单手查阅。

## 🚀 部署到 GitHub Pages 指南

1. 解压 `b737-torque-calculator.zip`，将文件夹内的全部文件上传至您的 GitHub 仓库根目录（含 `index.html`、`manifest.json`、`sw.js`、`css/`、`js/`、`data/`）。
2. 进入仓库 **Settings** → **Pages**，在 **Build and deployment** 下将 **Source** 设为 `Deploy from a branch`，选择 `main` 分支与 `/ (root)` 目录并点击 **Save**。
3. 等待约 1 分钟后即可通过 `https://<您的用户名>.github.io/<仓库名>/` 访问，在手机浏览器中点击“添加到主屏幕”即可像原生 App 一样离线使用。
