三、紧固件几何参数、材料等级与力矩核心物理定义
1. 标称直径 (Nominal Diameter) Shank & Major Dia

紧固件无螺纹光杆（Shank）或外螺纹大径的名义基准尺寸。直径代码 #10 (Dash 3 = 0.1900 in) 以下采用美标机螺钉编号（#2=0.0860", #4=0.1120", #6=0.1380", #8=0.1640", #10=0.1900"）；从 Dash 4 (1/4" = 0.2500 in) 起按 1/16 英寸 (0.0625 in) 递增（Dash 5 = 5/16" = 0.3125", Dash 6 = 3/8" = 0.3750", Dash 8 = 1/2" = 0.5000"）。

公式（Dash ≥ 4）：Nominal Dia (in) = Dash ÷ 16
2. 标称螺纹尺寸 (Thread Size) Dia - TPI

由标称外径（英寸小数）+ 每英寸牙数（TPI, Threads Per Inch）组成，是检索 AMM 20-50-11 所有力矩表纵行的唯一索引。例如 0.1900-32 代表外径 0.1900 英寸（#10）、每英寸 32 牙细牙；0.2500-28 代表外径 1/4 英寸、每英寸 28 牙细牙。

典型规格：0.1900-32 (#10-32) · 0.2500-28 (1/4-28)
3. 强度等级 (Fastener Class) KSI Tension / Shear

表征紧固件最小极限抗拉强度（FTU, Ultimate Tensile Strength）或极限抗剪强度（FSU, Ultimate Shear Strength），单位为 KSI（千磅/平方英寸，1 KSI ≈ 6.895 MPa）。分为抗拉型紧固件（Tension，长螺纹，如 160–200 KSI Table 203、220 KSI Table 201）与抗剪型紧固件（Shear，短螺纹，如 95–156 KSI Table 204）。

金属结构与复合材料结构同一紧固件所对应的强度表不同
4. 头部型式 (Head Style & Drive) Flush vs Protruding

分为100°沉头（Flush / Countersunk Head，含标准抗拉沉头与 Reduced Shear 薄型小沉头）和凸头（Protruding Head，含六角头 Hex、十二角双六角头 12-Point/Double Hex、盘头 Pan Head）。扳拧槽型含 Phillips 十字槽（NASM9006）、Torq-Set 偏置十字槽、内六角与外六角/十二角套筒。

气动外表面沉头螺钉常带贴合面密封胶，需查 Turn Head / Fay Seal 列
5. 螺纹制式与旋向 (Thread Type/Class) UNJF-3A / 3B RH

航空高强紧固件普遍采用符合 AS8879 (MIL-S-8879) 的 UNJF 螺纹。字母 J 表示受控增大的外螺纹牙底圆弧半径（0.15011P–0.18042P），显著降低牙底应力集中并提升抗疲劳寿命；3A 为最高精度外螺纹（螺栓）公差带，3B 为最高精度内螺纹（螺帽）公差带；默认均为右旋（Right Hand，顺时针旋紧）。

UNJF-3A = 精密受控根部半径外螺纹 · UNJF-3B = 精密内螺纹
6. 材料与采购规范 (Material & Spec) AMS / BPS-F-69 / BPS-N-70

三大主力材料：① 6Al-4V 钛合金 (AMS 4928/4967)：高比强度、耐腐蚀，广泛用于主结构与复合材料连接；② A286 沉淀硬化不锈钢 (CRES, AMS 5731/5737)：耐高温耐蚀（需查专属力矩表如 Table 205/207/220）；③ 低合金高强钢 (4340/8740)：表面镀镉 (QQ-P-416) 或涂覆铝涂层 (BMS10-85)。采购规范遵循 BPS-F-69 (螺杆) 与 BPS-N-70 (自锁螺帽)。

注意：A286 与 Monel 紧固件严禁套用普通钢/钛紧固件力矩表
7. 夹持长度 (Grip Size) 与总长 Grip & Thread Length (TL)

夹持长度 (Grip) 是从螺栓头部支承面（凸头底面或沉头理论最大直径点）到无螺纹光杆末端的精确轴向长度，以 1/16 英寸 (0.0625 in) 为单位。总长 L = Grip + TL (螺纹段长)。施工时必须保证光杆完全穿过结构剪切面（螺纹不得进入结构孔承载面），且螺帽拧紧后不得因光杆过长而“假到底 (Shank Bottoming)”，需用 ST8712H/J/K/L 量规检验伸出量。

垫圈规范：头部侧最多 1 片倒角垫圈 (BACS12FA)，螺帽侧最多 2 片平垫圈
8. Running Torque (跑合力矩 / 自锁摩擦力矩) Tare / Prevailing Torque

在螺帽底面尚未接触安装结构表面（未产生轴向预紧力 Preload）之前，将自锁螺帽旋过螺栓螺纹自锁变形段时测得的空转持续摩擦阻力矩。
• 根据 AMM 20-50-11 2.C.(6)：当使用需要在现场叠加跑合力矩的安装工况时，必须先用扭力扳手实测该自锁螺帽的 Running Torque，并将其直接加总到查表安装力矩值上（您可以在模块 4 的跑合力矩叠加计算器中一键自动合算）。

总目标力矩：Total Torque = Table Installation Torque + Running Torque
9. RUN ON TORQUE & 最大自锁力矩 (Max Locking) Max Installation Prevailing Torque

RUN ON TORQUE（旋入力矩）即螺帽旋入螺栓过程中（贴合支承面之前）出现的自锁阻力矩；最大自锁力矩 (Max Locking Torque) 是 AMM Table 227 与 BPS-N-70 规定的旋入力矩允许上限。若旋入阻力超过该上限，说明螺纹有毛刺、乱扣、异物或锁口过紧，继续强拧会导致螺纹咬死（Galling）或产生“假力矩”，必须立即拆下报废更换。

常见上限 (Table 227)：#10-32 = 18 in-lb · 1/4-28 = 30 in-lb · 5/16-24 = 60 in-lb
10. 最小脱扣力矩 (Min Breakaway Torque) Minimum Removal Prevailing Torque

用于检验自锁螺帽防松能力是否合格（能否重复使用 Re-use）的最低门槛。当螺帽已松开脱离结构支承面（无轴向载荷），但自锁收口段仍完全啮合在螺栓螺纹上时，开始逆时针转动螺帽所需的最小起始力矩。若实测值低于 AMM Table 227 规定的 Min Breakaway Torque，说明自锁弹性已失效，严禁复用，必须报废更换！

常见下限 (Table 227)：#10-32 = 2.0 in-lb · 1/4-28 = 3.5 in-lb · 5/16-24 = 6.5 in-lb

施工规范

AMM 20-50-11 章节 2.C.(1)–(12) 标准力矩核心准则 & BAC5009 规范

机务现场施工必读
2.C.(1)–(2) 手册优先级与紧固件安装准备General Priority

若具体飞机结构修理手册 (SRM)、工程图纸或特定章节 AMM 给出了专用力矩值，优先遵循专用图纸/章节规定；当图纸未规定具体力矩时，严格执行本标准力矩章节 (AMM 20-50-11)。

2.C.(3)(a)–(c) 力矩表选择与紧固件件号检索Table Selection

根据螺杆或螺帽的基础件号（波音标准件取前8位，如 BACB30NN）检索适用表格。当高强度螺杆配合低强度螺帽（或反之）安装时，必须分别查出螺杆与螺帽各自的允许力矩，并取两者中较低的力矩值 (Lower Torque Value)，严禁超拧较弱零件！

2.C.(3)(d) 金属部件 vs 复合材料部件安装Metal vs Composite

凡紧固件穿过或夹持非金属/复合材料结构（CFRP / 玻璃钢），必须选用复合材料专用力矩表（Table 213–225，如 Table 215/216），防止过大的轴向预紧力压溃复合材料层合板；全金属结构选用金属力矩表（Table 201–212）。

2.C.(4)–(5) 扭力扳手精度与设定原则Torque Wrench Accuracy

预置式（Preset）扭力扳手允许误差为 ±3%，非预置指针/数显式扭力扳手允许误差为 ±5%。当力矩表给出范围（如 30–35 in-lbs）时，优先将扳手设定在范围中值；若给出单一数值（如 35 in-lbs），按上述百分比公差控制。

2.C.(6) 自锁跑合力矩叠加与加长接杆修正公式Running Torque & Adapter

使用加长接杆（Adapter）时，扭力扳手设定读数 M = T × L ÷ (L + E)（其中 T 为目标力矩，L 为扳手力臂长，E 为接杆沿力臂方向延伸长；若接杆与扳手成 90° 垂直，则 E = 0 无需修正）。

2.C.(7)–(9) 干/湿润滑力矩判定准则Dry vs Lubed Threads

干力矩 (Dry) 适用于未涂覆附加润滑剂或带干膜后缀 D 的紧固件；润滑力矩 (Lubed) 适用于涂有鲸蜡醇 (Cetyl Alcohol，如后缀 K)、发动机滑油，或使用带铝涂层（后缀 A，BMS10-85）的紧固件。严禁在未经授权的情况下擅自给干态紧固件涂抹滑油！

2.C.(10) 拧螺帽 vs 拧螺杆头 / 贴合面密封胶Turn Nut vs Turn Head / Fay Seal

常规推荐固定螺杆头并转动螺帽 (Turn the Nut)；若因空间受限必须转动螺杆头 (Turn the Fastener Head)，或结构贴合面之间涂有贴合面密封胶 (Fay Surface Sealant)，为克服光杆与密封胶/孔壁摩擦損失，必须查 TURN THE FASTENER HEAD AND/OR FAY SEAL 列。

2.C.(11)–(12) 开口销对齐与自锁螺帽检验Cotter Pin & Self-Locking Check

城堡螺帽对齐开口销孔时，只允许在最小力矩基础上继续顺时针拧紧至最大开口销对齐力矩，严禁退松螺帽来对孔！所有自锁螺帽旋入与拆卸时均须满足 Table 227 的最大自锁力矩与最小脱扣力矩限值。
